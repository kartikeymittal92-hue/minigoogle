Why Google Changed Search

🕰️ The Old Method: Keyword Stuffing

Early search engines ranked pages simply by counting how many times a keyword appeared. This was easy to game — a spammer could repeat "pizza" 100 times on a blank page and outrank legitimate restaurants.

🚨 Spam example:
pizza pizza pizza pizza pizza pizza pizza pizza pizza pizza
➜ 10 keyword hits → ranks #1 (but totally useless!)

🚀 PageRank: Votes from the Web

Larry Page & Sergey Brin realised that a hyperlink from one website to another is like a recommendation. If many trusted sites link to you, you become important — just like academic citations in research papers.

✅ PageRank logic:
best-pizza-pune.com is linked to by 3 sites.
➜ High PageRank → ranks #1 (genuinely popular!)

🔁 Iterative Convergence

PageRank isn't calculated in one pass. The algorithm runs repeatedly — each iteration refines every page's score using updated neighbour scores — until values stop changing (convergence).

Formula:
PR(A) = (1–0.85) + 0.85 × Σ(PR(T) / C(T))

• d = 0.85 — damping factor (probability user follows a link)
• PR(T) — score of linking page
• C(T) — total outbound links from T

⚖️ Not All Votes Are Equal

A link from a high-PageRank page is worth more than a link from a low-ranked page. This mirrors real life — a recommendation from an expert matters more than one from an unknown source.

Example in this dataset:
best-pizza-pune.com (site 2) has PR ≈ 1.6 and links to sites 1 & 3.
➜ Sites 1 & 3 inherit significant score from site 2.
